### 1. 근거 패널: 추정값 · 측정소 실측 · CCTV 사진 나란히 (S4)
- 왜: 교수님 피드백이 "이 예측 농도가 어떻게 나온 거냐"였습니다. 패널 하나로 **CCTV 사진 → 모델 추정값, 그리고 근처 측정소 실측**을 같이 보여 줘서 답합니다
- 데이터: `/api/point`의 `camera` (`shared/mock/point_inside.json`). 사진은 `photo_url`
  - `photo_url`은 `/cam/…`으로 시작하는 서버 기준 주소입니다. 배포 서버(같은 주소)에서는 그대로, `?api=http://localhost:8000`처럼 API 주소를 따로 줄 때는 그 앞에 붙이고, mock에서는 `/cam/` → `../shared/mock/cam/`으로 바꿔 씀
  - 지금 mock 모드의 `getPoint()`(`app.mjs`)는 예시 칸(`point_inside.json`의 `grid_id` 52, 연수구 송도 쪽)을 눌렀을 때만 `station`을 붙입니다. `camera`도 같은 방식으로 붙이면 됩니다
  - **실제 서버의 `/cam/` 사진도 이미 나옵니다**(11/8 확인). 낮 회차마다 카메라별 최신 1장을 가려서 덮어씁니다. 예: https://incheon-air.duckdns.org/cam/10042.jpg (밤에는 그날 마지막 낮 사진이 남아 있음)
    - 다만 "누른 곳에서 어느 카메라의 어떤 회차인지"를 알려 주는 `camera` 정보는 백엔드(S3)가 아직이라, 패널 연결은 mock으로 먼저 만듭니다
    - `/cam/live/…`(직접 해보기 사진)는 버튼을 눌러 추정해야 생깁니다. 지금 404가 정상
  - **`station`(측정소 실측)은 실제 서버에서도 나옵니다**(2026-11-07, 백엔드 PR #8). 배포 주소나 `?api=https://incheon-air.duckdns.org`로 지금 패널에 실측이 뜨는지 확인할 수 있습니다
    - 예: 송도 센트럴파크 → `{"name":"아암","distance_km":1.4,"pm25":8.0,"data_time":"2026-11-07T22:00:00+09:00","period":"21~22시 평균"}`
    - 그 측정소의 최근 값이 비면 `pm25: null`(다른 시각·측정소로 메우지 않음). 측정 시각 `data_time`을 꼭 같이 보여 주세요
    - `camera`는 아직 백엔드에 없습니다(S3). mock으로 만듭니다
- 보여 줄 것
  - 사진 위쪽 60%(모델이 보는 곳)에 **붉은 테두리**, 그 **좌상단에 작은 네모 라벨 "ROI"**. 우상단에는 CCTV 자체 날짜·시각 글자가 있어 피함. 사진 파일에 그리지 말고 화면에서 겹쳐 그리기(CSS나 canvas). 완성 모양 참고: `shared/mockup/roi_example.jpg`
  - 아래 40%는 이미 모자이크돼서 오므로 브라우저에서 따로 가리지 않음
  - 카메라 이름, 거리, 촬영 시각(`captured_at`), 그 사진의 추정값(`pm25`). `pm25`가 null이면 `status` 문장을 그대로(예: "비(60분 강수량) — 추정 안 함")
  - 밤에는 마지막 낮 사진이 옵니다. "16:40 촬영 · 밤에는 측정소 기반"처럼 시각을 꼭 붙이기
  - `camera`가 null이면 사진 칸을 숨김
- 배치는 자유입니다. 컴퓨터에서 추정값 · 실측 · 사진이 한눈에 비교되면 됩니다
- 완료 기준: `?mode=mock`에서 예시 칸(연수구 송도 쪽)을 누르면 세 가지가 나란히 나옴. 밤 mock에서도 사진 시각이 보임

### 2. 직접 해보기 버튼 (S5)
- 왜: 관람객이 직접 눌러서 "**지금** 이 카메라 사진으로 추정"되는 과정을 봅니다(33분에 누르면 33분 사진)
- 패널의 사진 옆에 "지금 찍어서 추정해 보기" 버튼 → `POST /api/infer?camera_id=` (예시 `shared/mock/infer_ok.json`·`infer_rain.json`·`infer_busy.json`)
- 응답까지 **10~15초** 걸릴 수 있습니다. 기다리는 동안 단계 연출: ① 사진 찍는 중 → ② 위쪽 60% 잘라내기(1번의 붉은 ROI 테두리를 여기서 보여 주면 자연스러움) → ③ 모델 계산 → ④ 결과. 실제 진행과 맞출 필요는 없고 기다림이 지루하지 않으면 됨
- 결과: 새 사진(`photo_url`), 값과 등급, 촬영 시각, `elapsed_s`. `cached: true`면 "방금 누른 결과" 표시
- mock: 개발용 서버(`python -m http.server`)는 POST를 받지 못합니다. mock 모드에서는 POST 대신 예시 JSON을 읽고 10초쯤 기다렸다가 보여 주세요(`scenario=infer_rain`, `scenario=infer_busy` 같은 식으로 경우 바꾸기)
- 실패
  - 409: "다른 분이 추정 중이에요. 잠시 뒤 다시"
  - 503·네트워크 오류: "지금은 할 수 없어요" + 1번 패널의 회차 사진·값을 그대로 보여 주기
  - `pm25`가 null: `status` 문장(비·습도·밤)
- VM에서 측정해 보니 **약 12초**(사진 받기 5 · 모델 불러오기 5 · 추정 1)라 이 기능은 합니다. 단계 연출을 이 순서와 비슷하게 맞추면 자연스럽습니다. 서버가 실패할 때를 대비해 연출 부분과 API 부르는 부분은 나눠 두세요
- 완료 기준: mock에서 정상·비·진행 중 세 경우가 각각 맞게 보임

### 3. 원리 페이지 틀 (S6)
- 왜: "어떻게 나온 값인가"를 길게 설명하는 곳. 지도에서 "원리" 버튼으로 엽니다
- `web/about.html`(지도와 같은 글꼴·색). **팀장 초안(11/7)이 나와서 절과 그림 자리를 거기에 맞췄습니다.** 페이지 제목은 "도로 CCTV로 초미세먼지를 읽을 수 있을까?"
  | 절 | 내용 | 그림 자리 |
  |---|---|---|
  | 1. 질문 | 측정소는 동네마다 없지만 CCTV는 곳곳에 있다 | 없음 |
  | 2. 가설 | 먼지가 많으면 먼 건물·산이 뿌옇게 보인다 | 없음 |
  | 3. 데이터 | CCTV 20대·20분마다, 정답은 에어코리아 측정소, 비·습도 95%↑ 뺌, 배운 기간과 채점 기간 | 없음(짧은 목록) |
  | 4. 방법 | 위쪽 60%만 보는 이유(ROI), 모델, 습도 | 1장 (같은 카메라의 맑은 날·탁한 날) |
  | 5. 결과 | 얼마나 틀리나, 습한 날 착각이 줄어든 것, 모델이 본 곳, 실제 서비스 값과 실측 | **4장** (오차 비교 막대, 습도 치우침, 모델이 본 곳 히트맵, 날짜별 실측 대조) |
  | 6. 한계 | 정답(측정소)도 흔들림, 탁한 날 낮게 부름, 밤·비·아주 습한 날은 추정 안 함, 카메라마다 다른 눈금, 공식 측정값 아님 | 없음(짧은 목록) |

  - 그림은 대부분 가로로 긴 그래프·사진 쌍입니다. 컴퓨터 화면에서 본문 폭을 꽉 채워 크게 보이게 해 주세요
  - 결과 절의 마지막 그림(실측 대조)은 전시 전날(11/10)에 들어옵니다
- 팀장이 글을 직접 고칠 수 있게, 글은 HTML 안에 평범한 문단으로(자바스크립트로 만들지 않기)

### 4. 검색 (S9)
- 장소 이름이나 주소를 치고 **엔터** → 그 위치로 이동하고 1번 패널을 띄움(클릭과 같은 동작)
- [Nominatim](https://operations.osmfoundation.org/policies/nominatim/)을 브라우저에서 바로 부릅니다(키 없음). 규칙은 [AGENTS.md](../AGENTS.md) "화면 규칙"의 검색 줄: 엔터 때만, 1초 1번 이하, 인천으로 제한, **자동완성 금지**
  - 예: `https://nominatim.openstreetmap.org/search?q=인천시청&format=json&limit=1&countrycodes=kr&viewbox=126.35,37.65,126.85,37.35&bounded=1`
  - 팀장이 해 보니 "인하공업전문대학", "인천시청", "부평역", "송도 센트럴파크", 도로명 주소는 찾고 "인하공전"(줄임말)은 못 찾음 → 안내문 "정식 이름이나 주소로 검색"
- 결과 없음·서비스 범위(인천 내륙·송도) 밖: 짧은 안내
- 완료 기준: 위 예시 검색어로 이동·패널, 없는 이름은 안내

### 5. 전시용 주소 `?expo=1` (S10) — **맨 마지막. 못 해도 됩니다**
- 왜: 전시가 해 진 뒤라도 그날 마지막 낮 CCTV 회차 지도를 보여 주려고. 메뉴에는 걸지 않고 전시 노트북만 이 주소로 엽니다
- `?expo=1`이면 `/api/frames/latest`와 `/api/point`에 `source=cctv`를 붙여 부름(A의 5번). 화면에 "전시용 · 오늘 16:40 회차"처럼 표시
- 못 하면 전시 때 밤에는 실서비스 화면(측정소 기반)을 띄웁니다
