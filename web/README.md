# 인천 에어맵 — B 프론트

빌드 없는 HTML/CSS/ES modules + MapLibre GL JS 4.7.1 / OpenFreeMap Liberty.
`web/`만 수정했으며 `shared/`를 읽어서 사용합니다. CCTV 사진은 API가 제공한 모자이크 사진만 표시합니다. 첫 화면에는 카메라/측정소 위치 마커를 표시하지 않습니다.

## 실행

저장소 루트에서:

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

- 낮 mock: http://localhost:8766/web/?mode=mock
- 밤 mock: http://localhost:8766/web/?mode=mock&scenario=night
- 갱신 지연: http://localhost:8766/web/?mode=mock&scenario=stale
- 아직 값 없음: http://localhost:8766/web/?mode=mock&scenario=empty
- 실제 API: http://localhost:8766/web/?api=http://localhost:8000
- 테마 고정: 주소에 `&theme=dark` 또는 `&theme=light` (평소에는 인천 일몰 시각으로 자동)

실제 API 모드는 CORS 허용 후 사용합니다. 기본 `/web/`는 동일 출처 `/api`를 호출합니다.
실패해도 mock으로 자동 전환하지 않습니다. 환경변수/인증키/설치 과정은 없습니다.
`file://`로는 모듈/fetch를 사용할 수 없습니다. 지도·라이브러리 CDN에 인터넷이 필요합니다.
내 위치는 HTTPS 또는 localhost에서 사용자 권한 허용 후 동작합니다.

## 디자인 (11/9 리디자인)

- 색·글자·간격·움직임 변수는 `style.css` 맨 위 한곳에 있다. 글꼴은 Pretendard(SIL OFL) 분할본을 jsDelivr에서 받는다(`style.css` 맨 위 `@import`). 못 받으면 맑은 고딕으로 보인다.
- 일몰 후에는 다크(`theme.mjs`, 서버 `sun.py`와 같은 태양고도 식). 데이터 상태 "밤"(측정소 지도)과는 별개다. 1분마다 다시 판정한다.
- 지점을 새로 고르면 패널 숫자는 0부터 올라가고 게이지 점은 왼쪽 끝에서 제자리로 간다(`evidence.mjs`의 `reveal`). 1분 갱신으로 다시 그릴 때는 움직이지 않는다.
- 바탕 지도는 낮에는 liberty 원래 색이고(글자만 `--map-label`), 밤에만 `map-theme.mjs`가 `--map-*` 색으로 덮어 칠한다.
- 지도 구름은 낮에는 등급 안에서 농도별로 진해지는 옅은 색(`cloudColor`), 밤에는 범례와 같은 등급색 한 색이고, 경계는 흐림 처리로 부드러워진다.
- 비교 문장("실측보다 2㎍/㎥ 높아요")은 두 값의 시각 차이가 90분 이하이고 CCTV 지도일 때만 쓴다.
- 첫 화면 카메라 점은 `shared/cameras.json`에서 격자가 있는 19대, 값 유무는 `/api/frames/latest`의 `camera_ids`.

### F2·F18 카카오 장소 검색
입력이 0.3초 멈추면(두 글자부터) 후보 목록을, Enter를 누르면 결과를 `${base}/api/search?q=`로 가져옵니다. API 키는 서버에만 있으며 프론트에는 설정하지 않습니다. Enter 결과는 한 개면 즉시 선택, 여러 개면 이름·주소 목록 최대 5개에서 고릅니다. 선택한 이름을 패널 제목에 표시하고 지도 직접 클릭 시에는 구 이름으로 돌아갑니다. 빈 결과·인천 밖·서비스 범위 밖·503/연결 실패를 구분합니다.

자동완성 중에는 이동이나 상태 안내를 하지 않습니다. localStorage와 메모리 검색 결과 캐시는 없습니다. 요청에 `cache: no-store`를 사용하고 결과는 현재 화면에만 둡니다. 예전 Nominatim 설정 파일은 제거했습니다. 모바일 검색은 돋보기 버튼으로 펼치고 다시 누르거나 Escape로 접습니다. 닫으면 선택이 없는 첫 화면은 `mobileHome()`으로 다시 계산합니다.

- `?mode=mock&scenario=search_ok`: 이름 결과 여러 개
- `scenario=search_address_ok`: 지번 결과 한 개
- `scenario=search_empty`, `search_outside_incheon`, `search_outside_area`, `search_error`: 상태·503 안내
- 실제 확인: `?api=https://incheon-air.duckdns.org`에서 지번 `용현동 88-16` 입력

### F13·F14 상태·근거 이유
`?mode=mock&sample=1`에 `scenario=night`, `rain`, `few`, `humidity`, `no_data`, `legacy`로 상태를 확인합니다. 기본/밤/비/부족은 `shared/mock/next/` 응답을 그대로 사용하고, humidity/no_data는 비 예시에서 reason만 바꾼 개발용 시나리오입니다. `scenario=fallback`은 건너뛴 CCTV·측정소와 이유를 표시합니다. 원인을 모르는 카메라 코드는 추측하지 않습니다. 사진이 없는 패널은 두 칸 폭으로 줄입니다.

일반 주소에서 지도가 측정소 기반이면 접속 때 이유를 알리는 안내창을 한 번 띄웁니다(`frame-status.mjs`의 `noticeFor`, 탭마다 상태별 한 번, 전시 주소에서는 안 띄움).

### F8 근거 위치 / F3 지도 복원 / F6 패널 배치
근거 핀은 `/api/point`가 반환한 `station`·`camera` 좌표만 사용합니다. 별도 측정소/카메라 목록을 읽거나 가짜 근거를 찾지 않습니다. 첫 화면에는 핀이 없고, 선택 시 확정 시안 3의 핀·가장자리 방향 표시·상세 상자가 나옵니다. 핀을 그리는 것 자체는 지도 시점을 바꾸지 않습니다. 핀을 누르면 선택 지점 위치를 유지하며 필요한 만큼 줌아웃하고, 다시 누르거나 상세 ×를 누르면 기존 시점으로 돌아갑니다. 작은 화면에서 상세는 스크롤 가능한 별도 상자로 표시합니다.

원리 링크로 떠날 때 카메라 시점(중심·줌·기울기·방향·여백)과 선택 좌표만 sessionStorage에 저장하고, 돌아올 때 한 번만 복원합니다. 카카오 검색 결과·장소 이름은 저장하지 않으므로 복원 패널 제목은 구 이름입니다. 새 주소로 열면 첫 화면입니다. 패널 여백은 화면 35% 같은 최소값 대신 실제 높이로 계산합니다.

`?expo=1`로 열면 최신 프레임·지점 조회에만 `source=cctv`를 추가합니다. 메뉴에는 노출하지 않습니다. 실제 회차 날짜·시각을 보여 주므로 과거 데이터를 오늘로 오인하지 않습니다. 백엔드가 옵션을 지원하지 않고 station을 반환하면 미지원/측정소 기반임을 명시합니다. `?mode=mock&sample=1&scenario=night&expo=1`로 마지막 낮 CCTV 회차를 확인합니다. 이 옵션은 즉석 추정을 낮으로 바꾸지 않으며, 전시 주소의 밤에는 사진을 새로 찍지 않고 마지막 낮 회차 사진·값·촬영 시각으로 같은 단계를 보여 줍니다. 일반 주소에서 지도가 측정소 기반(밤·비·습도·카메라 부족)이면 CCTV 칸과 핀을 빼고 두 칸으로 표시합니다.

### E2 머지·배포 후 비상 녹화
모든 PR이 머지되고 팀장이 서비스에 반영한 다음, 실제 서비스에서 아래 순서로 1~2분 녹화해 팀장에게 파일로 전달합니다(저장소에는 넣지 않음).
1. 실제 기준 시각·범례가 보이는 전체 지도(약 10초).
2. 송도 지점을 누르고 추정·측정소·CCTV ROI와 각각의 시각 비교(약 20초).
3. 지금 찍어서 추정 버튼 → 대기 단계 → 새 사진과 결과(약 20~30초).
4. 장소 검색으로 이동하고 원리 페이지의 방법·결과·한계 확인(약 30초).
5. 전체 지도·근거 패널·즉석 결과·원리 페이지를 각각 캡처.
현재 mock은 실제 서비스 녹화를 대신하지 않습니다. `NEXT.md` 항목과 그림5가 머지·배포된 뒤 위 절차로 최종 확인합니다.
